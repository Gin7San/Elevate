InterviewSense

AI-powered mock interviews and multimodal confidence assessment.

Stack

  • Frontend: React, TypeScript, Vite
  • Backend: Node.js, Express, TypeScript
  • Database: PostgreSQL with Prisma
  • Planned analysis: Whisper, MediaPipe, Librosa, and an LLM API

Start PostgreSQL 

docker compose up -d

Install dependencies 

npm install
npm run install:all

Copy backend/.env.example to backend/.env, then initialize Prisma. The API now includes POST /api/v1/auth/register, POST /api/v1/auth/login, and protected GET /api/v1/me routes.

Initialize Prisma:

cd backend
npx prisma migrate dev --name init

Run the app

From the project root:

npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:4000/health
